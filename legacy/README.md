# CUSTO Legacy HTML Prototypes Archive

This directory contains the original single-file HTML prototype interfaces created during initial concept validation for AAS Hospital & Pathology (Wardha):

1. `index.html`: Original single-page landing and star rating interface.
2. `feedback.html`: Original 1-4 star private feedback submission form targeting Google Apps Script.
3. `review-generator.html`: Original 1715-line 5-star review generator containing sentence combinator algorithms and Wardha healthcare sentence banks.

All core functionality, sentence libraries, and micro-interactions from these legacy files have been fully migrated into the Next.js TypeScript application (`app/`, `services/ReviewEngine.ts`, `lib/db.ts`).
